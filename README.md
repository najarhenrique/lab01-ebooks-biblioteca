# Sistema de Gestão de eBooks da Biblioteca Universitária

Projeto desenvolvido para a disciplina de **Laboratório de Projeto de Software**.

## Descrição Resumida do Sistema
O sistema permite a gestão do acervo de livros digitais (eBooks) disponibilizados pela biblioteca de uma universidade. Os alunos podem adicionar à sua estante pessoal até 4 eBooks obrigatórios e 2 livres durante períodos de acesso no semestre. A equipe de bibliotecários gerencia o cadastro dos títulos, formatos e licenças de uso, além de consultar a distribuição dos títulos entre os alunos.
